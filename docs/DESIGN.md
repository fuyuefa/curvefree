# 设计原则

## 对标参照

公开资料里力量工具的共性（非抄袭像素）：

- **工具向**：打开即记录，无社交噪音
- **数据优先**：重量、次数、容量可读，偏「表格 + 大按钮」
- **信息架构**：底栏「今日 / 训练 / 饮食 / 我的」。今日承接续练、本周进度、肌群点（当天有计划时标题为「今天会练到」）、进入「近一周趋势」、今日计划。有未完成训练时，今日只留一张主色描边的续练主卡（计划日或动作名、已经进行的分钟、已记组数和大约容量，主按钮「接着练」），今日计划收成文字链「改用今日计划动作」。这条链、训练页开始、计划页「按此日开练」共用同一张底部确认：继续当前、结束并开新、取消。结束并开新会把当前课标成已完成，组数留在那一课里，再开新的。完成训练前的确认展示组数、容量、总时长；这次若记下了组间休息，再拆开休息和墙上时间。训练记录承接容量条、组行、加一组、完成本次训练。

线框 v1.4 锁定流程与文案口径（用「计划」，经期在「我的」而不在引导）。视觉只换气质。

引导收集 8 屏：性别（仅女 / 男）→ 身体 → 目标 → 每周天数 → 三个训练场景 → 经验 → 偏好（胸、背、肩、腿、臀、手臂、核心，文字芯片，可跳过）→ 日常活动。欢迎和完成页不计入这 8 屏。「数据不上传」只写在今日。经期在「我的」里记录月经天数、周期天数和可选的最近来潮日。饮食首页按早餐 / 午餐 / 加餐 / 晚餐记一笔，同一餐可以记多笔，并可改克数。用户可见中文句末不加「。」。

## 视觉 v3.2「奶油香芋」

权威色值在 `lib/core/constants/curve_palette.dart`，经 `buildCurveFreeTheme` 提供日间 / 夜间 `ThemeData`。表面禁止纯白 `#FFFFFF`、纯黑 `#000000`。

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| primary | `#9B7EBD` | `#B8A0D4` | 主行动、进度、底栏活跃 |
| accent | `#E8C4A8` | `#E8C4A8` | 今日细条、进度端点 |
| success | `#7B9E8E` | `#95B5A6` | 组完成 |
| screen | `#FBF7F2` | `#17141A` | 屏底 |
| card | `#FDF9F5` | `#211E24` | 卡片 |
| elevated | `#FCFAF6` | `#2E2A30` | 底栏、浮层 |

圆角：卡片 20、主按钮 18、chip 为 pill。屏边距 16，块间距 12。底栏高 56 加安全区。

组件从 `CurveColors.of(context)` 取色，使后续页面继承同一套日夜主题。外观切换在「我的」，默认跟随系统，只留在本机内存。
