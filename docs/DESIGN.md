# 设计原则（foundation）

## 对标参照（训记等力量工具）

公开资料与产品描述中的共性（非抄袭像素）：

- **工具向**：打开即训练/记录，无社交噪音
- **数据优先**：重量、次数、容量可读性强，偏「表格 + 大按钮」效率
- **暗色底**：健身房/OLED 场景下近黑背景减少眩光（产品选择，非默认套皮）

## 曲线自由视觉 token

| Token | 值 | 用途 |
|-------|-----|------|
| `bg` | `#0A0A0A` | 页面底 |
| `surface` | `#161616` | 卡片/分区 |
| `surfaceHigh` | `#222222` | 抬起层 |
| `text` | `#F2F2F2` | 主文字 |
| `textMuted` | `#8A8A8A` | 次要说明 |
| `accent` | `#3DDC97` | 主行动（避免紫色系套皮） |
| `danger` | `#FF6B6B` | 破坏性操作 |
| `radius` | `12` | 控件圆角 |
| `space` | `8` 基准栅格 | 间距 |
