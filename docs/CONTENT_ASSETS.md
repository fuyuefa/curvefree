# 内容与素材许可

| 资产 | 来源 | 许可 |
|------|------|------|
| `assets/lottie/*.json` | 本仓库原创几何循环（示意杠铃轨迹，非真人动作捕捉） | 与程序相同，GPL-3.0 |
| `assets/fonts/NotoSansSC-*.ttf` | Noto Sans SC，取拉丁与 GB2312 子集（Regular / SemiBold），避免 Web 首次绘制缺字 | SIL Open Font License 1.1，见同目录 `OFL.txt` |
| 动作名/分类（`ex_`） | 常见力量训练用语，由本项目维护，作为离线基线 | GPL-3.0 |
| 动作扩展 | `assets/content/exercises.json`，英文名与 `sourceId` 来自 free-exercise-db；中文名为项目译名；不含该库图片与说明长文 | Unlicense（上游）+ 译名 GPL-3.0 |
| 食物营养 | `assets/content/foods.json`。`usda` 行为 FoodData Central 公有领域典型值（`fdcId`）；`estimate` 为中餐粗算 | 见 `assets/content/ATTRIBUTION.md` |
